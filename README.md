# 🌦️ Live Weather Application

A modern and responsive weather application that provides real-time weather information for any city worldwide. Built using **Node.js**, **Express.js**, **EJS**, and the **OpenWeather API**.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 💧 Humidity information
- 🌬️ Wind speed
- ☁️ Weather condition with icon
- 📱 Responsive and clean UI
- ⚡ Fast weather data fetching using Axios
- ❌ Error handling for invalid city names

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- HTML5
- CSS3
- Bootstrap 5
- Axios
- OpenWeather API

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/live-weather-app.git
```

2. Navigate to the project folder

```bash
cd live-weather-app
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and add your OpenWeather API key

```env
API_KEY=YOUR_OPENWEATHER_API_KEY
```

5. Start the application

```bash
node app.js
```

6. Open your browser and visit

```
http://localhost:3000
```
